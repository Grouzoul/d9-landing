Branchez votre base. Gouvernez l'accès.

d9 est le fork open source de Directus : une API REST/GraphQL instantanée sur votre base, avec une gouvernance fine des droits — par rôle, par ligne, par champ. Là où l'original se referme, d9 reste ouvert.

Voir sur GitHub → docker compose up
Pourquoi maintenant

Directus bascule en commercial : licence active, fonctionnalités verrouillées, et l'énergie part vers un produit fermé. La base de contributeurs externes a fondu de moitié en deux ans.

d9 reprend le flambeau open : même socle éprouvé, 100 % libre et auto-hébergeable, maintenu en Europe — sans licence active ni fonctionnalité verrouillée.
